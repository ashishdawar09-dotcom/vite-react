# Legacy SQL (history only)

These scripts were pasted into the Supabase SQL editor by hand between May and
July 2026. Production never recorded which ones ran or in what order, and later
files redefine functions from earlier ones.

They are superseded by `../migrations/20261002000000_baseline.sql`, which was
generated from the live database catalog and verified to reproduce it exactly.

Do not run these files against any database. `seed_v12_bcsk.sql` and
`stress_test.sql` were never deployment steps.
